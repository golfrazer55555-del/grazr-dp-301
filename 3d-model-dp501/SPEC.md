# GRAZR DP-501 — 모델 치수와 근거

기준: 소유자 디자인 도안(`*-design.jpg`)과 소유자가 보낸 실물 사진(140–147). 사진과 도안이 다를 때 소유자가 사진을 지정한
부분(황동·검정 경계: 사진 144–146, 뒷면 곡선: 사진 147의 핑크 선)은 사진을 따랐습니다. 높이는 KSPO 실측 56 mm(도안 53 mm는
56/53배). 좌표: X 토우(−)→힐(+), Y 페이스(0)→뒤(+), Z 바닥(0)→위, 단위 mm.

사진 비교는 사진마다 실루엣(배경 제거된 윤곽)과 바닥 각인 위치로 카메라를 역산해, 모델을 그 카메라로 렌더하거나 선을 사진 위에
겹쳐서 했습니다(`build_dp501.py --match`, `check/photo_cams.json`, `check/match_*.png`).
