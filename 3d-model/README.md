# GRAZR DP-301 — 3D 모델

Blender(`bpy` 5.3)에서 Python 스크립트로 만든 모델입니다. 수치를 바꾸고 다시 빌드할 수 있습니다.

| 파일 | 내용 |
|---|---|
| `build_dp301.py` | 모델링 스크립트 (스펙 상수는 파일 상단) |
| `dp301_putter.blend` | Blender 원본 (헤드·웨이트·샤프트·그립·데칼) |
| `dp301_putter.glb` | 웹 / AR / 다른 3D 툴용 (미터 단위) |
| `dp301_head.stl` | 헤드 + 엔드 웨이트, mm 단위 (3D 프린팅 / CAD 확인용) |
| `renders/` | 스튜디오 렌더 6장 |
| `mass_report.txt` | SUS304 기준 계산 무게 |

## 반영한 스펙
- 로프트 3°, 라이 74° (센터 샤프트, 힐 방향으로 기울어짐)
- 페이스 길이 108 mm, 다이아몬드 밀링 (±28°, 피치 4.4 mm, 깊이 0.35 mm)
- 샤프트 보어 9.4 mm (.370"), 34" 길이
- 블랙 CNC 코팅 바디, 폴리시드 SUS304 엔드 웨이트 (기어 각인 + 토크스 볼트)
- 사진 기준 형상: 높이 25 mm, 깊이 약 70 mm, 페이스바 두께 13 mm, 볼 컷아웃 R23.5

## 다시 빌드
```bash
pip install bpy==5.3.0
python3 3d-model/build_dp301.py              # 내보내기 + 렌더
python3 3d-model/build_dp301.py --no-render  # 내보내기만
```

## 무게 관련 참고
사진에서 잡은 외형(25 × 108 × 약 70 mm)을 SUS304 통짜로 만들면 약 860 g이 나옵니다.
그래서 내부를 이렇게 추정했습니다.
- 윙(원통)은 속이 빈 구조이고, 엔드 웨이트가 뒤에서 나사로 끼워지는 형태 (벽 두께 1.8 mm)
- 센터 웹 높이 6 mm

이렇게 해도 계산값은 약 497 g으로 스펙(395 g)보다 무겁습니다 (`mass_report.txt`).
실제 헤드에는 사진에 보이지 않는 내부 포켓이 있거나 실제 치수가 조금 작을 수 있습니다.
헤드 깊이·높이 실측값이나 단면 정보를 주시면 맞춰서 수정할 수 있습니다.
