# GRAZR DP-301 — 모델링 스펙 (사용자 제공)

용도: **홍보물 제작용 3D 모델** (렌더 이미지 / 웹 3D 뷰어)

## 기본 스펙
| 항목 | 값 |
|---|---|
| 로프트 | 3° |
| 라이 | 74° |
| 전체 무게 | 395 g |
| 헤드 무게 | 385 g (바닥 각인 `W.T/385g`) |
| 헤드 소재 | SUS 304 스테인리스 |
| 샤프트 소재 | 그래파이트 |
| 마감 | 100% CNC 밀링, 순수 블랙 도장 |
| 샤프트 구경 | 9.4 mm (.370") |

## 헤드 치수 (mm)
| 항목 | 값 |
|---|---|
| 페이스 길이 = 헤드 전체 폭 (힐–토) | 108 |
| 앞뒤 깊이 (페이스 → 날개 끝) | 68 |
| 페이스 높이 | 25 |
| 원통 날개 지름 | 25 |
| 원통 날개 길이 (앞뒤) | 55 |
| 가운데 반원 컷아웃 지름 | 42 |
| 페이스 바 두께 (앞뒤) | 14 |

## 날개 끝 무게추
- 지름 25 mm, 두께 2 mm, 개당 20 g
- 나사식 (교체용 무게추 별도 판매 없음 → 강조 불필요)
- 톱니 6개, 검은 점(구멍) 6개

## 샤프트 / 넥
- 퍼터 길이 34" (33" 주문 가능, 모델은 34")
- 센터 샤프트, 일자형, 헤드 정중앙 삽입
- 논오프셋, 페이스 밸런스

## 그립
- 길이 270 mm, 폴리우레탄
- 원형 단면 + 앞면 평평 (지름 29 mm, 평평한 면 폭 20 mm)

## 페이스
- 다이아몬드 밀링 (피치·깊이·각도는 사진 보고 추정)
- 테두리 여백 2 mm

## 로고 / 각인
- 벡터 파일 없음 → `logo.png` 및 사진에서 재구성
- 폰트 미상 → 사진과 비슷한 폰트로 대체
- 색상: 순수 블랙 (사진의 건메탈 톤은 조명 영향)

## 추가 자료
- 무게추, 그립 사진 추가 업로드 예정

## 추가 사진에서 확인한 디테일 (2026-11-13 업로드분)
- **페이스 밀링**: 대각선 교차선(약 ±32°)으로 만든 다이아몬드 격자. 다이아몬드 1칸 약 8.3 × 5.2 mm,
  각 다이아몬드 중앙에 짧은 가로 슬롯(약 2 mm). 토(toe) 쪽에 흰색 GR 로고. 페이스 외곽은 양끝이 둥근 스타디움 형태
- **뒷면(백바)**: GRAZR 각인(흰색) 양옆에 모서리가 둥근 사각 포켓 2개
- **윗면**: 페이스 바와 낮은 센터 웹 사이에 단차, 웹에 흰색 얼라인먼트 라인, 날개와 웹 사이에 오목한 필렛 홈
- **샤프트**: 페이스 바 정중앙에 삽입. 줄자 사진들에서는 무광 회색(건메탈) 샤프트로 보임 ← 색상 확인 필요
- **무게추**: 톱니 6개, 구멍 6개, 안쪽 원형 링, 중앙 토크스(별) 나사
- **그립**: 앞면 = 상단 흑색 GR 대형 로고 + 하단 회색 바탕에 흑색 GRAZR 세로 글자,
  옆면 = 회색 사선 그래픽 + "NON-SLIP", 뒷면 = 흑색, 전체에 작은 십자/대시 텍스처,
  그립 끝 캡 = 둥근 형태에 GR 로고 엠보싱 + 중앙 통기구멍
