# GRAZR DP-301 홍보 영상 (30초, 1920x1080, 30fps)

- 완성본: `out/GRAZR_DP-301_promo.mp4`
- 미리보기(브라우저): `index.html?play` 을 열면 실시간 재생 (음악 없음)
- 다시 렌더링: `node render.js`  (Playwright + ffmpeg 필요, 약 3분)
- 특정 시점 스틸: `node render.js out/x.mp4 --times=5,10.5`
