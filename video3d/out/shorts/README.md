## 올릴 때 참고

- **유튜브:** 16:9 영상은 쇼츠가 아니라 일반 영상으로 올라갑니다. 쇼츠 피드에 올리려면 9:16 세로 버전이 필요합니다. 일반 영상은 썸네일을 직접 지정할 수 있습니다.
- **인스타그램 릴스:** 16:9 영상도 올라가지만, 화면 위아래가 비어 보입니다. 피드 게시물이나 상세페이지에 더 잘 맞습니다.
- **순서:** 3번(타구음)과 5번(자립)처럼 바로 눈길을 끄는 영상부터 올리고, 이틀에서 사흘 간격으로 하나씩 올리는 것을 추천합니다.
- **음악 사용 조건:** 공개하기 전에 음악 "Stairway"(Patrick Patrikios)의 사용 조건을 확인하세요. 유료 광고에 쓸 계획이라면 특히 확인이 필요합니다.
