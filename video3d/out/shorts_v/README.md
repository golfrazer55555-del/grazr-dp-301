## 올리는 방법 (인스타그램)
1. **+ → 릴스** → 영상 선택 → **다음**
2. 음악은 이미 들어 있으니 인스타 음악을 **추가하지 마세요**.
3. **커버 수정 → 카메라 롤에서 추가** → 같은 번호의 `_thumb.jpg` 선택
4. 아래 문구를 붙여넣고 **공유**
5. 인스타 글에서는 주소를 눌러도 열리지 않습니다. 그래서 문구에 "프로필 링크"라고 썼습니다(프로필 링크 = grazr.co.kr).

유튜브 쇼츠용 제목·설명·태그는 맨 아래 **"유튜브 쇼츠"**에 따로 정리했습니다.

**해시태그:** 인스타그램은 게시물 하나에 해시태그를 **5개까지만** 받습니다. 아래 문구는 모두 5개로 맞춰 두었습니다.

## 유튜브 쇼츠

6개 모두 60초보다 짧은 세로 영상이라 올리면 자동으로 쇼츠가 됩니다. 올리는 순서는 위 인스타그램과 같게 했습니다(타구음 → 자립 → 공 집기 → 밀링 → 단조 → 센터 샤프트).
가격은 사이트(385,000원)와 스마트스토어(425,000원)가 달라서 넣지 않았습니다.
