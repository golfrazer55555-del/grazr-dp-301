## 올리는 방법 (인스타그램)
1. **+ → 릴스** → 영상 선택 → **다음**
2. 음악은 이미 들어 있으니 인스타 음악을 **추가하지 마세요**.
3. **커버 수정 → 카메라 롤에서 추가** → 같은 번호의 `_thumb.jpg` 선택
4. 아래 문구를 붙여넣고 **공유**
5. 인스타 글에서는 주소를 눌러도 열리지 않습니다. 그래서 문구에 "프로필 링크"라고 썼습니다(프로필 링크 = grazr.co.kr).

유튜브 쇼츠에 올릴 때는 같은 영상에 제목 끝에 `#shorts`를 붙이고, 설명에 `https://grazr.co.kr`를 그대로 쓰면 됩니다.

**해시태그:** 인스타그램은 게시물 하나에 해시태그를 **5개까지만** 받습니다. 아래 문구는 모두 5개로 맞춰 두었습니다.
`#GRAZR` `#퍼터` `#골프스타그램`은 매번 쓰고, 나머지 2개만 영상 내용에 맞게 바꿉니다.
유튜브 쇼츠에는 이 제한이 없어 `#shorts #그레이저 #DP301 #골프`를 더 붙여도 됩니다.
